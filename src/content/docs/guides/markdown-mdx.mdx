## MDX 组件

普通 `.md` 适合纯文本知识；`.mdx` 在 Markdown 中额外支持 `import` 和 JSX 组件。只有需要交互或 Starlight 组件时才用 MDX。

<CardGrid>
  <Card title="这是 MDX 卡片" icon="puzzle">
    它来自 `@astrojs/starlight/components`。<Badge text="MDX" variant="note" />
  </Card>
</CardGrid>

:::note[如何选择]
大多数文章用 `.md`；需要导入组件、写 JSX 或嵌入交互内容时再用 `.mdx`。
:::
