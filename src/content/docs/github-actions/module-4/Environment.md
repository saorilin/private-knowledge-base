## About Environment
GitHub Environment **不是 environment variable**。

Environment 表示一个运行或部署目标，例如：

- `testing`
- `staging`
- `production`

它可以拥有：

- Environment Secrets
- Environment Variables
- Required reviewers
- Branch/tag deployment rules
- Wait timer
- Deployment history

:::tip[Official Documentation]
[Managing environments for deployment - GitHub Docs](https://docs.github.com/en/actions/how-tos/deploy/configure-and-manage-deployments/manage-environments#creating-an-environment)
:::
